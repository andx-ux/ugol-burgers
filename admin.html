Подключение к GitHub

Чтобы сохранять изменения прямо на сайт, нужен личный токен доступа GitHub. Он останется только в этом браузере — никуда, кроме api.github.com, не отправляется.

  1. Откройте страницу создания токена (нужно быть залогинены в GitHub под тем же аккаунтом, что владеет репозиторием).
  2. В поле Repository access выберите Only select repositories → ugol-burgers.
  3. В Permissions → Repository permissions → Contents выберите Read and write.
  4. Нажмите Generate token и скопируйте его — он покажется только один раз.
  5. Вставьте токен в поле ниже.

Токен хранится в localStorage только этого браузера. Не открывайте эту страницу с чужого компьютера, не выйдя перед этим («Сменить токен» внизу после входа).

Правьте товары ниже и нажмите «Сохранить изменения» — сайт обновится сам за 30–60 секунд.

Изменения уходят напрямую в репозиторий на GitHub.
